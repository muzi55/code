# 대충 만든 자판

## 문제 설명

휴대폰 자판의 하나의 키에는 여러 문자가 할당될 수 있습니다.

예를 들어 1번 키에 `A`, `B`, `C`가 순서대로 할당되어 있다면:

- 1번 누르면 `A`
- 2번 누르면 `B`
- 3번 누르면 `C`

주어진 휴대폰 자판을 이용해서 특정 문자열을 입력할 때, **키를 최소 몇 번 눌러야 하는지** 구합니다.

같은 문자가 여러 키에 존재할 수 있으며, 이 경우 가장 적게 눌러서 입력할 수 있는 키를 사용합니다.

만약 목표 문자열에 있는 문자를 어떤 키로도 입력할 수 없다면 `-1`을 반환합니다.

## 제한사항

- `1 ≤ keymap.length ≤ 100`
- `1 ≤ keymap[i].length ≤ 100`
- `keymap`은 알파벳 대문자로 구성됩니다.
- `1 ≤ targets.length ≤ 100`
- `1 ≤ targets[i].length ≤ 100`
- `targets`는 알파벳 대문자로 구성됩니다.

## 입출력 예

| keymap               | targets            | result   |
| -------------------- | ------------------ | -------- |
| `["ABACD", "BCEFD"]` | `["ABCD", "AABB"]` | `[9, 4]` |
| `["AA"]`             | `["B"]`            | `[-1]`   |
| `["AGZ", "BSSS"]`    | `["ASA", "BGZ"]`   | `[4, 6]` |

## 핵심

각 문자를 입력하기 위해 필요한 **최소 키 입력 횟수**를 구한 뒤, `targets`의 각 문자열에 대해 필요한 횟수를 모두 더하면 됩니다.

입력할 수 없는 문자가 하나라도 존재하면 해당 문자열의 결과는 `-1`입니다.
