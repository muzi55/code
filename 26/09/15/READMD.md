# 01. 택배 박스 정리 시스템

## 문제

동일한 종류의 박스가 연속해서 쌓여 있을 경우, 하나만 남기고 중복된 박스를 제거한다.

박스의 기존 순서는 유지해야 한다.

> 이 문제는 **스택(Stack) 관점에서 해결한다.**

### 예시

```js
[2, 2, 5, 5, 5, 1, 1][
  // [2, 5, 1]

  (7, 7, 8, 8, 0, 0, 0)
];
// [7, 8, 0]
```

## 스택 관점에서 생각하기

스택은 **LIFO(Last In First Out)** 구조이며, 가장 마지막에 들어온 값을 `top`으로 확인할 수 있다.

이 문제에서는 스택의 마지막 값이 **직전에 처리한 박스**가 된다.

따라서 현재 박스와 스택의 마지막 박스를 비교한다.

```text
현재 박스 === stack의 마지막 박스
→ 연속된 중복이므로 넣지 않는다.

현재 박스 !== stack의 마지막 박스
→ 새로운 박스이므로 stack에 push한다.
```

예를 들어:

```text
입력: [2, 2, 5]

2
↓
[2]

다음 2
↓
stack top이 2이므로 무시
[2]

다음 5
↓
stack top인 2와 다르므로 push
[2, 5]
```

## 풀이

```js
function solution(boxes) {
  const stack = [];

  for (const el of boxes) {
    // 스택의 top과 현재 박스가 다를 때만 추가
    if (stack.at(-1) !== el) {
      stack.push(el);
    }
  }

  return stack;
}
```

## 동작 과정

입력이 `[2, 2, 5, 5, 5, 1, 1]`인 경우:

| 현재 값 | Stack       | 처리                       |
| ------- | ----------- | -------------------------- |
| 2       | `[2]`       | Stack이 비어 있으므로 추가 |
| 2       | `[2]`       | top과 같으므로 무시        |
| 5       | `[2, 5]`    | top과 다르므로 push        |
| 5       | `[2, 5]`    | top과 같으므로 무시        |
| 5       | `[2, 5]`    | top과 같으므로 무시        |
| 1       | `[2, 5, 1]` | top과 다르므로 push        |
| 1       | `[2, 5, 1]` | top과 같으므로 무시        |

최종 결과:

```js
[2, 5, 1];
```

## 핵심

- `stack.at(-1)` : 스택의 가장 마지막 값(top) 확인
- `stack.push()` : 새로운 박스를 스택에 추가
- 스택의 top과 현재 값을 비교하여 연속 중복을 판단
- 입력 순서를 그대로 유지하면서 중복 제거 가능

## 복잡도

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(n)`

배열을 한 번 순회한다.

최악의 경우 모든 박스가 서로 달라 모든 값을 스택에 저장하므로 공간 복잡도는 `O(n)`이다.
