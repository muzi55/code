# 문제 1. 짝수 먼저 처리하기 (큐)

## 문제 설명

정수 배열 `queue`와 정수 `k`가 주어집니다.

큐의 맨 앞 숫자를 하나씩 확인하며 다음 규칙을 적용합니다.

- 현재 숫자가 **짝수**라면 큐에서 제거하고 결과 배열에 추가합니다.
- 현재 숫자가 **홀수**라면 큐에서 제거한 뒤 큐의 맨 뒤로 다시 보냅니다.
- 결과 배열에 짝수가 총 `k`개 들어갈 때까지 반복합니다.

## 입력 형식

- `queue` : 정수 배열
- `k` : 뽑아야 하는 짝수의 개수

## 출력 형식

큐에서 뽑힌 짝수 `k`개를 순서대로 담은 배열을 반환합니다.

## 입출력 예시

```js
solution([1, 3, 4, 6, 5, 8], 3);
```

```js
[4, 6, 8];
```

## 기본 코드

```js
function solution(queue, k) {}
```

# 문제 2. 제한 값 대기열 (큐)

## 문제 설명

정수 배열 `queue`와 정수 `limit`이 주어집니다.

큐의 맨 앞 숫자를 하나씩 꺼내며 다음 규칙을 적용합니다.

- 현재 숫자가 `limit` 이상이면 큐에서 제거하고 결과 배열에 추가합니다.
- 현재 숫자가 `limit`보다 작으면 값에 `1`을 더한 뒤 큐의 맨 뒤로 다시 보냅니다.
- 큐가 완전히 빌 때까지 반복합니다.

## 입력 형식

- `queue` : 정수 배열
- `limit` : 기준이 되는 정수

## 출력 형식

`limit` 이상이 되어 큐에서 제거된 숫자들을 순서대로 담은 배열을 반환합니다.

## 입출력 예시

```js
solution([2, 4, 1], 4);
```

처리 과정:

```text
2 → 3으로 변경 후 뒤로 이동
4 → 결과에 추가
1 → 2로 변경 후 뒤로 이동
3 → 4로 변경 후 뒤로 이동
2 → 3으로 변경 후 뒤로 이동
4 → 결과에 추가
3 → 4로 변경 후 뒤로 이동
4 → 결과에 추가
```

결과:

```js
[4, 4, 4];
```

## 기본 코드

```js
function solution(queue, limit) {}
```
