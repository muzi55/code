## 문제

문자열 a의 글자를 재배열해 b를 만들 수 있으면 true를 반환하라. 모든 글자를 정확히 한 번씩 사용한다.

### 입력·반환·제한

각 길이 0~100,000. 영문 소문자.

### 예시

- 입력 인자: `["listen","silent"]`
- 반환값: `true`
- 설명: listen의 각 글자 수와 silent의 각 글자 수가 같다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(a, b)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

각 알파벳의 빈도가 모두 같으면 재배열 가능하다.

## 2. 첫 풀이를 평가하고 방법 고르기

두 문자열 정렬도 가능하지만 알파벳은 26개로 제한된다. 개수 차이를 누적하면 O(n+m)이다.

## 3. 손으로 실행해 보기

aab/abb: a에서 a:+2,b:+1. b를 빼면 a:+1,b:-1이라 0이 아니므로 실패.

## 4. 구현 순서와 맞는 이유

1. 길이가 다르면 false.
2. a의 문자 칸을 증가시킨다.
3. b의 문자 칸을 감소시킨다.
4. 모든 칸이 0인지 확인한다.

재배열은 위치만 바꾸므로 문자별 수가 같아야 하며, 수가 같으면 필요한 글자를 모두 배정할 수 있다.
