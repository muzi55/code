# 36. 잔액을 넘는 결제 거절

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 조건 확인 후 상태를 갱신하는 순서를 익힌다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

결제 요청을 순서대로 처리한다. 금액이 현재 잔액 이하면 승인하고 잔액에서 뺀다. 초과하면 거절하고 다음 요청을 계속 처리한다. [최종 잔액,승인 수]를 반환하라.

### 입력·반환·제한

balance 0~1,000,000,000. 요청 0~100,000개, 금액 1~10,000 정수.

### 예시

- 입력 인자: `[10,[7,5,3]]`
- 반환값: `[0,2]`
- 설명: 10에서 7 승인→3, 5 거절→3, 3 승인→0. 두 건 승인.
