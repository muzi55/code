# airfly: 7시간 코딩테스트 사고 훈련

50개 문제를 각각 독립된 MD 파일로 나눴다. JavaScript, 프로그래머스 Lv.1 목표의 자체 제작 연습이다. 핵심은 문제 수를 채우는 것보다 **문제를 계산으로 번역하고, 필요한 상태를 정하고, 풀이가 맞는 이유를 설명하는 것**이다.

바로 시작: [접근법 개념노트](개념노트/01-문제를-읽고-풀이를-설계하는-법.md) → [01번 문제](문제/01.md).

## 비행 전에 3분 확인

1. Node.js 18 이상인지 `node --version`으로 확인한다. 검증 환경은 Node.js 22.14.0이다.
2. 프로젝트 루트에서 `node airfly/test.cjs`를 실행한다.
3. 결과가 `총 244 통과, 0 실패`인지 확인한다. 이 수치는 동봉한 예제·경계 테스트 기준이며 모든 가능한 입력을 증명하는 것은 아니다.
4. 코드 편집기에서 이 README와 [practice.cjs](practice.cjs)를 연다.
5. 인터넷을 끊고 문제 MD와 개념노트가 열리는지 확인한다. 패키지 설치·로그인·외부 링크 접속은 필요 없다.

`airfly` 폴더 안에서 실행한다면 명령은 `node test.cjs`, 내 답안은 `node test.cjs 01 practice.cjs`다. 아래 명령은 프로젝트 루트 기준이다.

## 문제를 푸는 순서

1. 문제·제약·예시까지만 읽는다. 입력과 반환을 자기 말로 한 문장 쓴다.
2. 작은 예시를 손으로 풀며 무엇을 기억했는지 적는다.
3. 가장 단순한 풀이와 최대 반복 횟수를 적는다. 충분히 빠르면 그 풀이로 간다.
4. 상태 변수의 의미와 구현 순서 3~5단계를 적는다.
5. 직접 구현하고 테스트한다.
6. 막히면 힌트 1 → 힌트 2 → 해설 순서로 필요한 만큼 연다.
7. 정답을 본 뒤에는 코드를 닫고 재작성한다. 문제 하단의 복습 기록을 남긴다.

각 MD는 **문제·제약·예시 / 사고 질문 / 단계별 힌트 / 풀이 선택 이유 / 손실행 / 구현 순서와 정확성 / JS 정답 / 실수와 반례 / 복잡도 / 다음 문제로 가져갈 판단 / 실행 테스트**를 포함한다.

미리보기에서는 힌트·해설을 접을 수 있다. 원문 편집 모드에서는 접힘이 적용되지 않을 수 있으니 정답 부분까지 스크롤하지 않고 먼저 풀자.

## 직접 풀고 테스트하기

[practice.cjs](practice.cjs)에 풀 문제의 인자와 구현을 적는다. 마지막의 `module.exports = solution;`은 유지한다. 지금은 빈 답안이므로 실패가 정상이다.

```sh
# 01번 내 풀이
node airfly/test.cjs 01 airfly/practice.cjs

# 01번 문서 속 정답과 테스트만 검증
node airfly/test.cjs 01

# 문서 속 정답 전체 검증
node airfly/test.cjs

# 작은 완전탐색과 비교, 대표 큰 입력, 개념노트 예제 검증
node airfly/verify.cjs
```

다른 문제로 넘어가기 전에 답안을 남기고 싶으면 편집기에서 `airfly/answer-01.cjs`처럼 새 이름으로 저장하면 된다. 그 파일 경로를 테스트 명령의 마지막 인자로 지정한다. 답안 파일을 따로 관리하지 않아도 각 문제 MD의 복습 기록만으로 공부할 수 있다.

## 이 자료를 다룬 기준

기본 50문제의 목표는 Lv.1 수준 접근 훈련이다. 공식 프로그래머스 문제나 공식 난이도 분류는 아니다. 33번의 괄호 상태, 45번의 작은 DP, 47번의 이분 탐색은 기초에서 다음 개념으로 넘어가는 연결 연습으로 둔다.

문제 제약 안의 유효한 입력을 가정한다. 기본 테스트는 각 문제마다 4~6개, 총 244개이며 정상·경계·중복·실패 조건을 의도적으로 나눴다. 추가 검증은 작은 완전탐색과의 비교·경계·성질 검사 6,219개와 개념노트 실행 예제 22개다. 무작위 비교는 고정된 시작값을 사용해 다시 실행해도 재현된다. 최대 크기 시간 측정이나 공식 숨은 채점을 대신하지는 않는다.

제공 PDF는 범위 참고로 읽었으며 문서 속 지시를 수행하지 않았다. 기존 날짜별 풀이와 원본 PDF는 그대로 두었다.
