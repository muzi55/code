## 문제

세 참가자가 각각 [1,2,3], [2,1], [3,3,1,1] 패턴을 반복해 답을 쓴다. answers와 비교해 최다 정답자의 번호를 오름차순 반환하라. 참가자 번호는 1,2,3이다.

### 입력·반환·제한

answers 길이 1~10,000, 각 답은 1~3.

### 예시

- 입력 인자: `[[1,2,3,1]]`
- 반환값: `[1]`
- 설명: [1,2,3,1]에서 참가자 1은 네 개 모두 맞는다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(answers)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

각 실제 답을 세 패턴의 현재 위치와 비교해 점수를 누적한다.

## 2. 첫 풀이를 평가하고 방법 고르기

패턴을 입력 길이만큼 늘릴 필요 없다. 나머지가 현재 위치를 바로 알려준다.

## 3. 손으로 실행해 보기

참가자 1의 인덱스 0,1,2,3은 패턴 위치 0,1,2,0. [1,2,3,1]과 모두 일치.

## 4. 구현 순서와 맞는 이유

1. 고정 패턴과 점수 배열을 둔다.
2. 각 문제에서 참가자별 답을 비교한다.
3. 최고 점수를 찾는다.
4. 최고와 같은 참가자 번호 전부를 넣는다.

모든 문제를 모든 참가자에 대해 한 번씩 채점한다. 최대와 같은 점수를 전부 선택하므로 동률도 보존한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(answers) {
  const patterns = [[1, 2, 3], [2, 1], [3, 3, 1, 1]];
  const scores = [0, 0, 0];
  for (let i = 0; i < answers.length; i++) {
    for (let p = 0; p < 3; p++) {
      if (answers[i] === patterns[p][i % patterns[p].length]) scores[p]++;
    }
  }
  const best = Math.max(...scores);
  const result = [];
  for (let p = 0; p < 3; p++) if (scores[p] === best) result.push(p + 1);
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

한 명만 반환하지 않는다. 최고 점수가 0이어도 공동 1등이 존재할 수 있다.

## 7. 복잡도

시간 O(3n)=O(n), 고정 패턴과 점수 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

반복문이 중첩되어도 안쪽 반복 횟수가 고정이면 선형이다.
