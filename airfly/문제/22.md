# 22. 동률을 포함한 안내 순서

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 여러 우선순위를 비교 함수로 옮긴다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

[이름,점수] 목록을 점수 높은 순, 동점이면 이름 사전순으로 정렬하고 이름 배열을 반환하라. 이름은 모두 다르다.

### 입력·반환·제한

1~10,000명. 이름은 소문자 1~20글자, 점수 0~100.

### 예시

- 입력 인자: `[[["zoe",90],["ben",80],["amy",90]]]`
- 반환값: `["amy","zoe","ben"]`
- 설명: 90점인 amy,zoe가 이름순으로 앞에 오고 80점 ben이 뒤에 온다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(people)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

```sh
node airfly/test.cjs 22 airfly/practice.cjs
```

## 1. 문제를 계산으로 번역하기

비교(a,b)=점수 차이의 역순, 같으면 이름 오름차순.

## 2. 첫 풀이를 평가하고 방법 고르기

이름과 점수를 따로 정렬하면 연결이 깨진다. 항목 전체를 비교해 순서를 만든다.

## 3. 손으로 실행해 보기

zoe90와 amy90는 점수가 같아 amy가 먼저. ben80은 두 사람보다 뒤.

## 4. 구현 순서와 맞는 이유

1. 목록을 복사한다.
2. 점수가 다르면 높은 점수가 앞.
3. 점수가 같으면 이름을 비교한다.
4. 이름만 추출한다.

각 비교는 문제에 주어진 우선순위를 그대로 따른다. 따라서 정렬 결과도 그 순서를 만족한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(people) {
  return [...people].sort((a, b) => {
    if (a[1] !== b[1]) return b[1] - a[1];
    return a[0] < b[0] ? -1 : a[0] > b[0] ? 1 : 0;
  }).map(person => person[0]);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

비교 함수에서 true/false만 반환하지 않는다. 앞/동일/뒤를 음수/0/양수로 구분한다.

## 7. 복잡도

이름 길이 최대 20. 통상 O(n log n) 시간, O(n) 복사·결과 공간.
