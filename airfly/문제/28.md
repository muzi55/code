## 문제

출발 시각을 분 단위 정수로 나타낸 times에서 서로 다른 두 항목의 시간 차이 최솟값을 반환하라. 하루 안의 직선 시간이며 자정을 순환하지 않는다.

### 입력·반환·제한

길이 2~100,000. 각 값 0~1,439. 같은 시각이 있어도 된다.

### 예시

- 입력 인자: `[[30,5,18]]`
- 반환값: `12`
- 설명: [30,5,18] 정렬 결과 [5,18,30]에서 간격은 13과 12다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

함수 형태: `solution(times)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

시간순 정렬 후 오른쪽-왼쪽을 계산한다.

## 2. 첫 풀이를 평가하고 방법 고르기

모든 쌍 O(n²) 대신 정렬한다. 비인접 두 값 사이에는 인접 간격이 들어 있어, 비인접 차이가 그보다 작아질 수 없다.

## 3. 손으로 실행해 보기

[5,18,30]: best=Infinity → 18-5=13 → 30-18=12.

## 4. 구현 순서와 맞는 이유

1. 숫자 정렬한 복사본을 만든다.
2. i=1부터 이전 항목과 차이를 구한다.
3. 작은 차이를 남긴다.

모든 비인접 차이는 하나 이상의 음이 아닌 인접 차이의 합이다. 최솟값은 인접쌍에서 발견된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(times) {
  const sorted = [...times].sort((a, b) => a - b);
  let best = Infinity;
  for (let i = 1; i < sorted.length; i++) best = Math.min(best, sorted[i] - sorted[i - 1]);
  return best;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

중복 시각이면 답은 0이다. 0과 1439의 차이는 이 문제에서 1439이지 1이 아니다.

## 7. 복잡도

통상 시간 O(n log n), 복사 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단
