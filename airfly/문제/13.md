## 문제

가장 많이 등장한 메뉴 번호를 반환하라. 주문 횟수가 같으면 번호가 작은 메뉴를 반환한다.

### 입력·반환·제한

길이 1~100,000. 메뉴 번호 1~1,000.

### 예시

- 입력 인자: `[[3,2,3,2,1]]`
- 반환값: `2`
- 설명: 3번과 2번이 각각 두 번 등장하므로 작은 번호 2가 답이다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(orders)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

먼저 번호→횟수 표를 만들고, 횟수 내림차순·번호 오름차순 기준으로 하나를 고른다.

## 2. 첫 풀이를 평가하고 방법 고르기

각 메뉴마다 전체 주문을 다시 세면 O(n²)이 된다. 한 번 집계하고 표를 한 번 확인하면 된다. 정렬은 필수가 아니다.

## 3. 손으로 실행해 보기

[3,2,3,2,1] → {3:2,2:2,1:1}. 3을 후보로 두었다가 동률인 2가 작아서 교체한다.

## 4. 구현 순서와 맞는 이유

1. Map에서 횟수를 누적한다.
2. 첫 주문을 best로 둔다.
3. 더 높은 횟수 또는 같은 횟수의 작은 번호면 교체한다.

표의 각 후보를 같은 우선순위로 비교하므로 마지막 best가 전체 후보 중 최선이다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(orders) {
  const counts = new Map();
  for (const id of orders) counts.set(id, (counts.get(id) ?? 0) + 1);
  let best = orders[0];
  for (const [id, count] of counts) {
    if (count > counts.get(best) || (count === counts.get(best) && id < best)) best = id;
  }
  return best;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

마지막에 등장한 메뉴를 우선하지 않는다. 동률 기준은 명시된 번호다.

## 7. 복잡도

평균 시간 O(n+k), 공간 O(k). k는 메뉴 종류 수.
