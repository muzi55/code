권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

영문 대문자를 알파벳 순서로 shift칸 뒤로 옮겨라. Z 다음은 A이고 공백은 그대로 둔다.

### 입력·반환·제한

text 길이 0~100,000. 대문자와 공백만 포함. shift는 0~1,000,000 정수.

### 예시

- 입력 인자: `["YZ A",2]`
- 반환값: `"AB C"`
- 설명: Y,Z,A를 두 칸 옮기면 A,B,C이고 공백은 유지된다.

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

## 1. 문제를 계산으로 번역하기

문자→0 기준 정수→순환 이동→문자로 되돌리는 변환이다.

## 2. 첫 풀이를 평가하고 방법 고르기

shift번 이동하면 너무 많은 반복이 생긴다. 몇 바퀴를 돌든 나머지만 중요하므로 문자마다 한 번 계산한다.

## 3. 손으로 실행해 보기

Y=24: (24+2)%26=0→A. Z=25→1→B. A=0→2→C.

## 4. 구현 순서와 맞는 이유

1. 공백은 보존한다.
2. charCodeAt에서 A의 코드 65를 뺀다.
3. 이동 후 %26을 적용한다.
4. 65를 더해 문자로 복원한다.

0~25의 모든 위치는 나머지 계산으로 정확히 한 순환 위치에 대응한다. 26의 배수 이동은 제자리다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(text, shift) {
  const result = [];
  for (const ch of text) {
    if (ch === ' ') result.push(ch);
    else result.push(String.fromCharCode(65 + (ch.charCodeAt(0) - 65 + shift) % 26));
  }
  return result.join('');
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

문자 코드 자체에 %26을 적용하면 A의 기준이 어긋난다. 공백은 이동 대상이 아니다.

## 7. 복잡도

n=길이. 시간 O(n), 반환 포함 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단

요일, 원형 좌석, 순환 배열도 ‘0 기준 위치+이동량을 크기로 나눈 나머지’로 표현할 수 있다.
