권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

명령 ['IN',이름]은 줄 끝에 추가한다. ['OUT']은 맨 앞 사람을 내보내고 이름을 결과에 기록한다. 빈 줄이면 'EMPTY'를 기록한다. OUT 결과만 배열로 반환하라.

### 입력·반환·제한

명령 0~100,000개. 이름은 대문자 1~20글자, 'EMPTY'는 이름으로 사용하지 않는다.

### 예시

- 입력 인자: `[[["IN","A"],["IN","B"],["OUT"],["OUT"],["OUT"]]]`
- 반환값: `["A","B","EMPTY"]`
- 설명: A,B 순서로 들어오면 A,B 순서로 나가고 세 번째 OUT은 EMPTY다.

## 1. 문제를 계산으로 번역하기

IN은 push, OUT은 head가 길이보다 작으면 queue[head++]를 기록.

## 2. 첫 풀이를 평가하고 방법 고르기

매번 shift하면 큰 배열에서 앞 삭제 비용이 누적될 수 있다. head 방식은 각 명령을 상수 시간에 처리한다.

## 3. 손으로 실행해 보기

IN A, IN B → queue=[A,B],head=0. OUT→A,head=1. OUT→B,head=2. OUT→EMPTY.

## 4. 구현 순서와 맞는 이유

1. 배열, head=0, 결과를 만든다.
2. IN은 뒤에 넣는다.
3. OUT은 남은 항목 여부를 보고 읽는다.

head는 처리할 때마다 하나씩 증가하고 삽입은 끝에만 하므로 먼저 들어온 항목이 먼저 읽힌다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(commands) {
  const queue = [];
  const result = [];
  let head = 0;
  for (const [type, name] of commands) {
    if (type === 'IN') queue.push(name);
    else result.push(head < queue.length ? queue[head++] : 'EMPTY');
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

queue.length===0으로 빈 줄을 판단하지 않는다. 이미 읽은 항목도 배열에는 남아 있어 head===length를 확인한다.

## 7. 복잡도

시간 O(n), 공간 O(n). 완료된 항목도 함수가 끝날 때까지 배열에 남는 유한 배치 처리다.

## 8. 다음 문제에서 꺼낼 판단
