## 문제

0 이상 정수 n의 십진수 각 자릿수를 더해 반환하라.

### 입력·반환·제한

0 ≤ n ≤ 1,000,000,000. 반환은 정수.

### 예시

- 입력 인자: `[5072]`
- 반환값: `14`
- 설명: 5072의 각 자리 5+0+7+2는 14다.

## 코딩 전에 직접 적기

## 1. 문제를 계산으로 번역하기

끝자리 하나를 떼어 더하고, 그 끝자리가 없는 숫자로 같은 작업을 반복한다.

## 2. 첫 풀이를 평가하고 방법 고르기

문자열로 바꿔도 가능하다. 여기서는 %10과 Math.floor(/10)으로 반복이 어떻게 작아지는지 연습한다. 원래 수만큼 반복할 필요는 없다.

## 3. 손으로 실행해 보기

5072 → 507 → 50 → 5 → 0. 떼어 낸 값 2,7,0,5. sum 0 → 2 → 9 → 9 → 14.

## 4. 구현 순서와 맞는 이유

1. sum=0, remaining=n.
2. remaining%10을 더한다.
3. remaining을 10으로 나눈 정수 몫으로 줄인다.
4. 0이 되면 끝낸다.

n의 각 자리가 정확히 한 번 나머지로 나온다. remaining은 매번 작아져 종료한다. n=0은 합 0을 바로 반환한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  let sum = 0;
  let remaining = n;
  while (remaining > 0) {
    sum += remaining % 10;
    remaining = Math.floor(remaining / 10);
  }
  return sum;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

`remaining /= 10`만 하면 소수 부분이 남는다. 숫자 0도 입력 범위에 포함된다.

## 7. 복잡도

d=십진 자릿수. 시간 O(d), 추가 공간 O(1). n>0이면 d는 O(log n).

## 8. 다음 문제에서 꺼낼 판단

‘한 자리씩’, ‘마지막 자리’는 나머지와 정수 몫을 떠올린다. 진법이 b이면 10을 b로 바꾼다.
