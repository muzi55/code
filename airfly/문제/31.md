# 31. 연속 안내 신호 줄이기

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 전체 중복과 인접 중복을 구분한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

같은 숫자가 연속으로 나온 구간을 각각 하나로 줄여 반환하라. 떨어져서 다시 나온 같은 숫자는 유지한다.

### 입력·반환·제한

길이 0~100,000, 원소 0~9.

### 예시

- 입력 인자: `[[1,1,2,1,1]]`
- 반환값: `[1,2,1]`
- 설명: 1,1은 하나로 줄이고 중간 2 이후 다시 나온 1은 남긴다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(signals)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

```sh
node airfly/test.cjs 31 airfly/practice.cjs
```

## 1. 문제를 계산으로 번역하기

결과가 비었거나 마지막 값과 다르면 현재 신호를 추가한다.

## 2. 첫 풀이를 평가하고 방법 고르기

Set은 멀리 떨어진 같은 신호까지 없앤다. 마지막 원소만 비교하는 한 번의 순회로 충분하다.

## 3. 손으로 실행해 보기

[1,1,2,1,1] → [1] → [1] → [1,2] → [1,2,1] → 유지.

## 4. 구현 순서와 맞는 이유

1. 결과 배열을 만든다.
2. 빈 배열이면 첫 값을 넣는다.
3. 마지막 값과 다를 때만 추가한다.

각 연속 구간의 첫 원소만 추가된다. 다른 신호 뒤 재등장하면 마지막 값이 달라 다시 추가된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(signals) {
  const result = [];
  for (const x of signals) {
    if (result.length === 0 || result[result.length - 1] !== x) result.push(x);
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

[1,2,1]은 그대로 남아야 한다. 0을 빈 값처럼 취급하지 않는다.

## 7. 복잡도

시간 O(n), 결과 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단

중복의 범위가 전체인지 연속 구간인지 먼저 표시한다. 12번과 비교하자.
