권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

승객 나이가 담긴 ages에서 minimum세 이상인 승객 수를 반환하라. 같은 나이가 여러 번 나와도 서로 다른 승객이다.

### 입력·반환·제한

ages 길이 0~100,000, 나이와 minimum은 0~120 정수. 반환은 정수.

### 예시

- 입력 인자: `[[8,12,18],12]`
- 반환값: `2`
- 설명: 12세와 18세가 기준 12세 이상이므로 2명이다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(ages, minimum)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

각 나이에 대해 age >= minimum이 참이면 1, 거짓이면 0을 더한다.

## 2. 첫 풀이를 평가하고 방법 고르기

모든 승객을 한 번은 확인해야 한다. 정렬 후 찾을 수도 있지만 개수만 필요하므로 순회 O(n)이면 충분하다. 중복을 없애면 사람 수가 사라진다.

## 3. 손으로 실행해 보기

ages=[8,12,18], minimum=12. count: 0 → 0(8 제외) → 1(12 포함) → 2(18 포함).

## 4. 구현 순서와 맞는 이유

1. count=0으로 시작한다.
2. 나이를 하나씩 꺼낸다.
3. 경계값을 포함하는 >=를 적용한다.
4. 전체를 확인한 뒤 count를 반환한다.

매 단계에서 새 승객 한 명만 정확히 반영한다. 마지막에는 모든 승객이 한 번씩 반영되어 개수가 맞는다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(ages, minimum) {
  let count = 0;
  for (const age of ages) {
    if (age >= minimum) count++;
  }
  return count;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

`>`는 기준과 같은 사람을 제외한다. [12],12는 1이어야 한다. 빈 배열의 답은 0이다.

## 7. 복잡도

n=ages.length. 시간 O(n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

‘조건을 만족하는 개수’는 조건식+카운터부터 생각한다. 반환이 명단으로 바뀌면 카운터 대신 결과 배열이 필요하다.
