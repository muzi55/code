권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

기념품 이름 items에서 같은 이름은 최초 등장 하나만 남겨 원래 순서대로 반환하라. 대소문자를 구분한다.

### 입력·반환·제한

길이 0~100,000. 이름은 길이 1~20 영문자.

### 예시

- 입력 인자: `[["cup","bag","cup","pen","bag"]]`
- 반환값: `["cup","bag","pen"]`
- 설명: cup,bag의 두 번째 등장은 건너뛰고 pen은 남긴다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(items)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

이름이 seen에 없을 때만 저장한 뒤 seen에 표시한다.

## 2. 첫 풀이를 평가하고 방법 고르기

매번 result.includes로 찾으면 서로 다른 이름 n개에서 O(n²) 비교가 생긴다. Set으로 존재 확인을 분리한다.

## 3. 손으로 실행해 보기

cup→추가, bag→추가, cup→이미 존재, pen→추가, bag→이미 존재.

## 4. 구현 순서와 맞는 이유

1. Set과 결과 배열을 만든다.
2. 처음 본 이름이면 결과와 Set에 넣는다.
3. 결과를 반환한다.

처음 등장할 때만 추가하고 이후에는 seen이 막는다. 따라서 각 이름이 정확히 한 번, 최초 순서대로 남는다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(items) {
  const seen = new Set();
  const result = [];
  for (const item of items) {
    if (!seen.has(item)) {
      seen.add(item);
      result.push(item);
    }
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

sort는 첫 등장 순서를 바꾼다. 'Cup'과 'cup'은 서로 다르다.

## 7. 복잡도

해시 조회 평균 O(1) 가정, 시간 O(n), 공간 O(k). k는 서로 다른 이름 수. 이름 길이는 최대 20.

## 8. 다음 문제에서 꺼낼 판단

‘전에 나왔나’만 물으면 Set. 등장 횟수나 최근 위치도 필요하면 Map을 고려한다.
