## 문제

문자열 a의 글자를 재배열해 b를 만들 수 있으면 true를 반환하라. 모든 글자를 정확히 한 번씩 사용한다.

### 입력·반환·제한

각 길이 0~100,000. 영문 소문자.

### 예시

- 입력 인자: `["listen","silent"]`
- 반환값: `true`
- 설명: listen의 각 글자 수와 silent의 각 글자 수가 같다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(a, b)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

```sh
node airfly/test.cjs 17 airfly/practice.cjs
```

## 1. 문제를 계산으로 번역하기

각 알파벳의 빈도가 모두 같으면 재배열 가능하다.

## 2. 첫 풀이를 평가하고 방법 고르기

두 문자열 정렬도 가능하지만 알파벳은 26개로 제한된다. 개수 차이를 누적하면 O(n+m)이다.

## 3. 손으로 실행해 보기

aab/abb: a에서 a:+2,b:+1. b를 빼면 a:+1,b:-1이라 0이 아니므로 실패.

## 4. 구현 순서와 맞는 이유

1. 길이가 다르면 false.
2. a의 문자 칸을 증가시킨다.
3. b의 문자 칸을 감소시킨다.
4. 모든 칸이 0인지 확인한다.

재배열은 위치만 바꾸므로 문자별 수가 같아야 하며, 수가 같으면 필요한 글자를 모두 배정할 수 있다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(a, b) {
  if (a.length !== b.length) return false;
  const counts = Array(26).fill(0);
  for (const ch of a) counts[ch.charCodeAt(0) - 97]++;
  for (const ch of b) counts[ch.charCodeAt(0) - 97]--;
  return counts.every(count => count === 0);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

종류가 같아도 횟수가 다르면 실패다. 소문자라는 제한 덕분에 26칸으로 충분하다.

## 7. 복잡도

시간 O(n+m), 추가 공간 O(26)=O(1).

## 8. 다음 문제에서 꺼낼 판단

## 테스트와 검증 의도

`args`는 함수 인자 목록이다. 배열 하나를 받는 함수는 `[[...]]`, 두 인자를 받으면 `[첫째, 둘째]`로 기록한다. 각 `name`은 무엇을 확인하는지 설명한다.

<!-- tests -->
```json
[
  {
    "name": "재배열",
    "args": [
      "listen",
      "silent"
    ],
    "expected": true
  },
  {
    "name": "횟수 차이",
    "args": [
      "aab",
      "abb"
    ],
    "expected": false
  },
  {
    "name": "길이 차이",
    "args": [
      "a",
      "aa"
    ],
    "expected": false
  },
  {
    "name": "빈 입력",
    "args": [
      "",
      ""
    ],
    "expected": true
  },
  {
    "name": "동일",
    "args": [
      "zz",
      "zz"
    ],
    "expected": true
  }
]
```
