# 35. 안내 로봇의 이동

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 명령을 상태 변화로 모델링한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

로봇은 (0,0)에서 시작한다. U는 y+1, D는 y-1, R은 x+1, L은 x-1이다. 모든 명령 후 [x,y]를 반환하라. 경계는 없다.

### 입력·반환·제한

명령 문자열 길이 0~100,000, U,D,L,R만 포함.

### 예시

- 입력 인자: `["UURDL"]`
- 반환값: `[0,1]`
- 설명: UURDL은 (0,0)→(0,1)→(0,2)→(1,2)→(1,1)→(0,1).

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(commands)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

각 명령을 좌표 증감으로 바꿔 순서대로 적용한다.

## 2. 첫 풀이를 평가하고 방법 고르기

문제는 경로 탐색이 아니라 주어진 명령 실행이다. DFS/BFS나 방문 집합이 필요하지 않다.

## 3. 손으로 실행해 보기

UURDL에서 x는 0→0→0→1→1→0, y는 0→1→2→2→1→1.

## 4. 구현 순서와 맞는 이유

1. 좌표를 0으로 초기화한다.
2. 명령마다 해당 축을 증감한다.
3. 두 좌표를 반환한다.

각 명령의 정의를 현재 좌표에 적용하므로 모든 명령 후 요구된 최종 위치가 된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(commands) {
  let x = 0;
  let y = 0;
  for (const command of commands) {
    if (command === 'U') y++;
    else if (command === 'D') y--;
    else if (command === 'R') x++;
    else x--;
  }
  return [x, y];
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

화면의 행 좌표와 달리 이 문제의 U는 y를 증가시킨다. 좌표 규칙은 문제 정의를 따른다.

## 7. 복잡도

시간 O(n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

‘명령이 주어짐’과 ‘갈 방법을 찾아야 함’을 구분하자. 전자는 시뮬레이션, 후자는 탐색 후보.
