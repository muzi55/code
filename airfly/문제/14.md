## 문제

두 사람이 가진 쿠폰 번호 배열 a,b에서 공통으로 가진 번호를 중복 없이 오름차순 반환하라.

### 입력·반환·제한

각 길이 0~100,000, 번호 1~1,000,000 정수.

### 예시

- 입력 인자: `[[4,2,2],[2,4,4,9]]`
- 반환값: `[2,4]`
- 설명: 공통 번호는 2,4이고 반복된 2는 하나만 남긴다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(a, b)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

b의 각 번호가 a에 존재하면 공통 집합에 넣고 마지막에 정렬한다.

## 2. 첫 풀이를 평가하고 방법 고르기

모든 a,b 쌍을 비교하면 최대 10^10번이다. Set 조회로 후보를 찾고 결과만 정렬한다.

## 3. 손으로 실행해 보기

a=[4,2,2], b=[2,4,4,9]. owned={4,2}; common은 {2}→{2,4}, 이후 반복과 9는 결과를 늘리지 않는다.

## 4. 구현 순서와 맞는 이유

1. a로 Set을 만든다.
2. b를 읽고 존재하는 번호만 common에 추가한다.
3. 배열로 바꿔 숫자 정렬한다.

두 배열에 모두 존재하는 값만 들어가며 Set이 중복을 없앤다. 마지막 정렬이 출력 순서를 충족한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(a, b) {
  const owned = new Set(a);
  const common = new Set();
  for (const id of b) {
    if (owned.has(id)) common.add(id);
  }
  return [...common].sort((x, y) => x - y);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

Set만 반환하면 요구한 배열 타입이 아니다. 기본 sort는 숫자 크기순이 아니다.

## 7. 복잡도

평균 O(n+m+k log k) 시간, O(n+k) 공간. k는 공통 종류 수. 정렬은 통상 O(k log k) 모델.

## 8. 다음 문제에서 꺼낼 판단

집합 연산과 출력 형식은 별개다. ‘공통 종류’와 ‘겹친 개수’도 구분한다.
