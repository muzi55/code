목표: 순위의 정의를 수식으로 정확히 옮긴다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

각 점수의 순위를 원래 순서대로 반환하라. 순위는 ‘자신보다 점수가 높은 사람 수+1’이다. 동점이면 같은 순위이며 다음 순위는 건너뛸 수 있다.

### 입력·반환·제한

길이 1~500. 점수 0~100.

### 예시

- 입력 인자: `[[80,90,80,70]]`
- 반환값: `[2,1,2,4]`
- 설명: 90은 1위, 80 둘은 2위, 70은 자신보다 높은 사람이 세 명이므로 4위.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(scores)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.


## 1. 문제를 계산으로 번역하기

answer[i]=1+count(scores[j]>scores[i]).

## 2. 첫 풀이를 평가하고 방법 고르기

n≤500이면 25만 비교라 이중 순회가 충분하다. 정렬+등수표도 가능하지만 이 문제에서는 정의를 그대로 구현한다.

## 3. 손으로 실행해 보기

[80,90,80,70]: 80보다 높은 수 1→2위. 90→1위. 다른80→2위.70→4위.

## 4. 구현 순서와 맞는 이유

1. 각 점수마다 rank=1.
2. 모든 점수와 엄격한 >로 비교한다.
3. 계산한 순위를 결과에 추가한다.

순위 정의에 들어가는 모든 사람을 빠짐없이 세며 동점은 세지 않는다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(scores) {
  return scores.map(score => {
    let rank = 1;
    for (const other of scores) if (other > score) rank++;
    return rank;
  });
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

동점을 높다고 세면 안 된다. 출력 순서는 점수순이 아니라 입력 순서다.

## 7. 복잡도

시간 O(n²), 반환 공간 O(n), 그 외 O(1).

## 8. 다음 문제에서 꺼낼 판단

제한이 작으면 명세의 정의를 직접 계산하는 풀이가 좋은 출발점이다. 10만 명으로 커지면 정렬+Map을 고려한다.
