권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

홀수 개 가격을 오름차순으로 나열했을 때 정가운데 가격을 반환하라. 원본 배열은 바꾸지 않는다.

### 입력·반환·제한

길이는 1~99,999 사이 홀수. 가격은 0~1,000,000 정수.

### 예시

- 입력 인자: `[[9,2,5]]`
- 반환값: `5`
- 설명: [9,2,5]를 [2,5,9]로 정렬하면 가운데는 5다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(prices)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

정렬된 배열의 n//2 위치를 읽는다.

## 2. 첫 풀이를 평가하고 방법 고르기

최솟값·최댓값의 평균은 가운데 가격과 다를 수 있다. 정렬은 전체 순위를 만들어 중앙 위치를 직접 읽게 한다.

## 3. 손으로 실행해 보기

[9,2,5] → [2,5,9], 길이 3 → 인덱스 1 → 5.

## 4. 구현 순서와 맞는 이유

1. 펼침 문법으로 복사한다.
2. 숫자 비교 함수로 정렬한다.
3. 가운데 값을 반환한다.

홀수 길이에서 n//2 앞뒤에는 같은 개수의 원소가 있다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(prices) {
  const sorted = [...prices].sort((a, b) => a - b);
  return sorted[Math.floor(sorted.length / 2)];
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

sort()만 쓰면 [2,10,3]이 [10,2,3]이 된다. sort는 호출한 배열을 변경한다.

## 7. 복잡도

통상 정렬 시간 O(n log n), 복사 공간 O(n). JS 정렬의 내부 공간은 엔진에 따라 다르다.

## 8. 다음 문제에서 꺼낼 판단
