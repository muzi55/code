# 43. 두 안내 방송의 공통 주기

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 최대공약수와 최소공배수의 의미를 연결한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

a분마다, b분마다 방송이 반복된다. [a와 b의 최대공약수, 두 방송이 동시에 다시 나오는 최초 양의 시간]을 반환하라. 처음에는 동시에 방송한다.

### 입력·반환·제한

a,b는 1~1,000,000 정수.

### 예시

- 입력 인자: `[12,18]`
- 반환값: `[6,36]`
- 설명: 12와 18의 최대공약수는 6, 최초 공통 양의 배수는 36이다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(a, b)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

나머지를 반복해 gcd를 얻고 lcm=(a/gcd)*b로 계산한다.

## 2. 첫 풀이를 평가하고 방법 고르기

시간을 1분씩 늘리면 최소공배수가 아주 클 때 느리다. 유클리드 호제법은 큰 수를 나머지로 줄인다.

## 3. 손으로 실행해 보기

(12,18)→(18,12)→(12,6)→(6,0). gcd=6, lcm=12/6×18=36.

## 4. 구현 순서와 맞는 이유

1. 원래 a,b를 보존하고 x,y에 복사한다.
2. y가 0이 될 때까지 [x,y]=[y,x%y].
3. x와 (a/x)*b를 반환한다.

a=qb+r이면 a,b의 공약수는 b,r의 공약수와 같다. 마지막 0이 아닌 수가 gcd다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(a, b) {
  let x = a;
  let y = b;
  while (y !== 0) [x, y] = [y, x % y];
  return [x, (a / x) * b];
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

최소공배수를 구할 때 반복문에서 줄어든 x,y를 원래 a,b 대신 사용하지 않는다.

## 7. 복잡도

시간 O(log min(a,b)), 추가 공간 O(1). 최대 곱 10^12는 JS 안전 정수 범위 안.

## 8. 다음 문제에서 꺼낼 판단

반복 주기의 일치는 최소공배수, 같은 크기로 최대 분할은 최대공약수와 연결된다.
