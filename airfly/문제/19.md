# 19. 쿠폰 번호 두 개로 목표 만들기

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 현재 값에 필요한 짝을 역산한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

nums의 서로 다른 두 인덱스를 골라 합이 target이 되면 true, 없으면 false를 반환하라. 값이 같은 두 원소도 인덱스가 다르면 선택할 수 있다.

### 입력·반환·제한

길이 0~100,000. 원소와 target은 -1,000,000~1,000,000 정수.

### 예시

- 입력 인자: `[[2,7,11],9]`
- 반환값: `true`
- 설명: 2와 7의 합이 9다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(nums, target)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

현재 값 x의 짝 target-x가 과거에 있었는지 검사한다.

## 2. 첫 풀이를 평가하고 방법 고르기

모든 쌍은 O(n²)로 최대 약 50억 쌍이다. 필요한 짝만 Set에서 찾으면 평균 O(n)이다.

## 3. 손으로 실행해 보기

[2,7,11],9: 2에서 7은 없음→2 저장. 7에서 2가 있음→true.

## 4. 구현 순서와 맞는 이유

1. 빈 Set을 둔다.
2. 짝이 있는지 먼저 검사한다.
3. 없으면 현재 값을 저장한다.
4. 끝까지 못 찾으면 false.

서로 다른 두 원소가 답이면 뒤의 원소를 읽을 때 앞의 원소가 Set에 있다. 자기 자신은 아직 넣지 않아 재사용되지 않는다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(nums, target) {
  const seen = new Set();
  for (const x of nums) {
    if (seen.has(target - x)) return true;
    seen.add(x);
  }
  return false;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

[4],8은 false다. 저장부터 하면 하나의 원소를 두 번 쓰는 오류가 생긴다.

## 7. 복잡도

해시 평균 시간 O(n), 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단

‘두 값의 관계’에서 하나를 고정해 다른 하나를 계산할 수 있으면 보완값 검색을 생각한다.
