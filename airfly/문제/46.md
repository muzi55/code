# 46. 좌석표 뒤집어 읽기

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 2차원 배열의 행과 열을 명확히 다룬다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

R행 C열 좌석표 seats를 전치해 C행 R열 배열로 반환하라. 원래 [r][c]의 값은 결과 [c][r]로 옮긴다.

### 입력·반환·제한

R,C는 1~100, 모든 행 길이는 같음. 원소는 0~1,000 정수.

### 예시

- 입력 인자: `[[[1,2,3],[4,5,6]]]`
- 반환값: `[[1,4],[2,5],[3,6]]`
- 설명: [[1,2,3],[4,5,6]]의 열들이 각각 [1,4],[2,5],[3,6]이라는 행이 된다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(seats)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

모든 좌표를 한 번씩 방문해 두 인덱스의 순서를 바꿔 넣는다.

## 2. 첫 풀이를 평가하고 방법 고르기

행렬이 꼭 정사각형이라고 가정하지 않는다. 출력 크기를 먼저 정하면 인덱스가 명확해진다.

## 3. 손으로 실행해 보기

seats[0][2]=3 → result[2][0]=3. seats[1][0]=4 → result[0][1]=4.

## 4. 구현 순서와 맞는 이유

1. R,C를 구한다.
2. 서로 독립적인 C개의 행을 만든다.
3. 각 원소를 [c][r]로 복사한다.

각 원래 좌표가 유일한 새 좌표에 대응하므로 모든 값이 한 번씩 옮겨진다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(seats) {
  const rows = seats.length;
  const cols = seats[0].length;
  const result = Array.from({ length: cols }, () => Array(rows));
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) result[c][r] = seats[r][c];
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

Array(cols).fill(Array(rows))는 같은 행 객체를 공유한다. 한 행을 바꾸면 다른 행도 함께 바뀐다.

## 7. 복잡도

시간 O(RC), 반환 공간 O(RC).

## 8. 다음 문제에서 꺼낼 판단

2차원 문제는 행 수, 열 수, 좌표 의미부터 써 놓는다. 입력이 직사각형인 반례를 꼭 넣는다.
