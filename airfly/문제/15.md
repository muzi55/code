# 15. 단 한 번 호출된 번호

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 최종 빈도와 최초 위치를 연결한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

calls에서 정확히 한 번 등장한 번호 중 가장 먼저 나온 번호를 반환하라. 없으면 -1을 반환한다.

### 입력·반환·제한

길이 0~100,000. 번호 0~1,000,000.

### 예시

- 입력 인자: `[[8,3,8,5,3,7]]`
- 반환값: `5`
- 설명: 8과 3은 반복되며 5와 7 중 먼저 나온 5가 답이다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(calls)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

```sh
node airfly/test.cjs 15 airfly/practice.cjs
```

## 1. 문제를 계산으로 번역하기

빈도가 1인 원소를 원본 배열에서 처음 찾는다.

## 2. 첫 풀이를 평가하고 방법 고르기

읽다가 바로 반환하면 뒤의 중복을 놓친다. 두 번의 순회는 O(2n)=O(n)이며 올바른 최종 정보를 제공한다.

## 3. 손으로 실행해 보기

[8,3,8,5,3,7] → 8:2,3:2,5:1,7:1. 원본을 다시 읽으면 처음 횟수 1은 5.

## 4. 구현 순서와 맞는 이유

1. 모든 번호의 횟수를 센다.
2. 원본 순서대로 횟수 1인지 확인한다.
3. 찾으면 즉시 반환, 없으면 -1.

두 번째 순회는 최종 빈도를 사용한다. 최초로 발견한 값이 요구한 가장 앞의 유일 번호다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(calls) {
  const counts = new Map();
  for (const id of calls) counts.set(id, (counts.get(id) ?? 0) + 1);
  for (const id of calls) {
    if (counts.get(id) === 1) return id;
  }
  return -1;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

0도 정상 번호다. `if (id)`로 찾음 여부를 판단하면 0을 놓친다.

## 7. 복잡도

평균 시간 O(n), 공간 O(k).

## 8. 다음 문제에서 꺼낼 판단

최종 통계가 필요한 조건은 집계 후 판단한다. 반복문 두 개가 순차적이면 곱이 아니라 합이다.
