## 문제

(와 )로만 된 text가 올바르게 짝지어지면 true를 반환하라. 모든 닫는 괄호 앞에는 대응하는 여는 괄호가 있어야 하고 마지막에 남는 괄호가 없어야 한다. 빈 문자열은 올바르다.

### 입력·반환·제한

길이 0~100,000.

### 예시

- 입력 인자: `["(())()"]`
- 반환값: `true`
- 설명: (())()는 모든 괄호가 순서에 맞게 짝지어진다.

## 1. 문제를 계산으로 번역하기

(면 +1, )면 -1. 중간에 음수가 되거나 마지막에 0이 아니면 실패.

## 2. 첫 풀이를 평가하고 방법 고르기

괄호 종류가 하나라 스택 전체 대신 개수만 저장할 수 있다. 단순 총합만 확인하면 순서 오류를 놓친다.

## 3. 손으로 실행해 보기

(())(): open 0→1→2→1→0→1→0. )(는 첫 단계 -1이라 즉시 실패.

## 4. 구현 순서와 맞는 이유

1. open=0.
2. 문자에 따라 증감한다.
3. 음수면 즉시 false.
4. 끝에서 open===0인지 반환한다.

음수가 아니면 모든 닫는 괄호에 이전의 여는 괄호가 있다. 마지막 0이면 미완료 여는 괄호도 없다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(text) {
  let open = 0;
  for (const ch of text) {
    open += ch === '(' ? 1 : -1;
    if (open < 0) return false;
  }
  return open === 0;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

‘총 여는 수=닫는 수’만으로 부족하다. 여러 종류의 괄호로 확장하면 개수만으로 순서를 검증할 수 없다.

## 7. 복잡도

시간 O(n), 추가 공간 O(1).
