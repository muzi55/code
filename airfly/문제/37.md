# 37. 순환 화면의 최종 번호

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 음수 이동에서도 유효한 나머지를 만든다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

0부터 size-1까지 화면이 원형으로 연결되어 있다. start에서 시작해 moves의 정수만큼 순서대로 이동한 최종 번호를 반환하라. 음수는 뒤로 이동이다.

### 입력·반환·제한

size 1~100,000, 0≤start<size. moves 길이 0~100,000, 이동량 -1,000,000~1,000,000.

### 예시

- 입력 인자: `[5,0,[-1,2]]`
- 반환값: `1`
- 설명: 크기 5에서 0→-1 이동은 4, 이어 +2 이동은 1이다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(size, start, moves)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

새 위치=((현재+이동)%size+size)%size.

## 2. 첫 풀이를 평가하고 방법 고르기

한 칸씩 이동하면 불필요한 반복이 커진다. 나머지로 한 번 계산하고 음수 나머지만 보정한다.

## 3. 손으로 실행해 보기

size=5,start=0: -1%5=-1 → +5로 4 → %5로 4. 다음 4+2=6 → 1.

## 4. 구현 순서와 맞는 이유

1. position=start.
2. 이동을 더하고 나머지를 계산한다.
3. size를 더한 뒤 다시 나머지를 구한다.

size의 배수만 더하거나 빼므로 원형 위치는 같고, 마지막 값은 반드시 유효 범위다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(size, start, moves) {
  let position = start;
  for (const move of moves) position = ((position + move) % size + size) % size;
  return position;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

(position+move+size)%size만 쓰면 -size보다 큰 음수 이동에서 여전히 음수가 될 수 있다.

## 7. 복잡도

시간 O(m), m=이동 횟수. 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

양방향 원형 이동은 단순 %보다 정규화한 나머지가 필요하다.

</details>
