## 문제

정수 n의 양의 약수 개수를 반환하라.

### 입력·반환·제한

1≤n≤1,000,000,000.

### 예시

- 입력 인자: `[36]`
- 반환값: `9`
- 설명: 36의 약수는 1,2,3,4,6,9,12,18,36 총 9개다.

## 코딩 전에 직접 적기

## 1. 문제를 계산으로 번역하기

d*d≤n인 후보만 보고 나누어떨어지면 짝 두 개를 센다. 같은 짝이면 하나만 센다.

## 2. 첫 풀이를 평가하고 방법 고르기

05번처럼 n까지 검사하면 10억 번이다. 약수의 짝을 이용하면 약 31,623개 후보만 검사한다.

## 3. 손으로 실행해 보기

36: (1,36),(2,18),(3,12),(4,9),(6,6). 앞의 네 쌍은 각 2개, 마지막은 1개라 9.

## 4. 구현 순서와 맞는 이유

1. d=1부터 d*d≤n까지 반복한다.
2. 나머지가 0이면 두 약수를 센다.
3. d*d===n이면 중복이므로 하나만 센다.

모든 약수 쌍의 작은 값은 √n 이하라 반드시 발견된다. 제곱근만 같은 값 두 번 세는 것을 피한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  let count = 0;
  for (let d = 1; d * d <= n; d++) {
    if (n % d === 0) count += d * d === n ? 1 : 2;
  }
  return count;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

d*d<n이면 제곱근 약수를 놓친다. 항상 +2하면 n=1도 2개로 잘못 센다.

## 7. 복잡도

시간 O(√n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

모든 후보를 보기 전에 대칭인 짝이 있는지 찾는다. 05번과 입력 상한을 비교하자.
