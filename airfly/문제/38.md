# 38. 연속 독서 최고 기록

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 현재 기록과 전체 최댓값을 따로 유지한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

days의 1은 독서한 날, 0은 하지 않은 날이다. 연속으로 독서한 날 수의 최댓값을 반환하라.

### 입력·반환·제한

길이 0~100,000, 원소는 0 또는 1.

### 예시

- 입력 인자: `[[1,1,0,1,1,1]]`
- 반환값: `3`
- 설명: [1,1,0,1,1,1]의 가장 긴 구간은 마지막 세 날이다.

## 1. 문제를 계산으로 번역하기

1이면 current+1, 0이면 current=0. 매번 best 갱신.

## 2. 첫 풀이를 평가하고 방법 고르기

각 시작점에서 다시 세면 O(n²)이 될 수 있다. 현재 구간은 이전 길이에 1을 더하거나 끊는 두 경우뿐이다.

## 3. 손으로 실행해 보기

current:1,2,0,1,2,3. best:1,2,2,2,2,3.

## 4. 구현 순서와 맞는 이유

1. current,best를 0으로 둔다.
2. 현재 값으로 current를 갱신한다.
3. 매번 best와 비교한다.

current는 해당 위치에서 끝나는 연속 구간의 길이이며, 모든 끝 위치를 검사하므로 최고 구간도 포함된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(days) {
  let current = 0;
  let best = 0;
  for (const day of days) {
    current = day === 1 ? current + 1 : 0;
    best = Math.max(best, current);
  }
  return best;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

0을 만날 때만 best를 갱신하면 마지막이 1로 끝나는 최고 구간을 놓친다.

## 7. 복잡도

시간 O(n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

‘지금 끝나는 답’과 ‘지금까지 전체 답’을 나누면 연속 구간 문제의 상태가 보인다.
