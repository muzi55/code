# 03. 가장 긴 비행 구간

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 최댓값과 위치를 함께 유지하고 동률 규칙을 구현한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

비행 구간의 소요 시간 durations에서 가장 긴 구간의 0부터 시작하는 인덱스를 반환하라. 동률이면 먼저 나온 구간을 반환한다.

### 입력·반환·제한

길이 1~100,000. 원소는 0~100,000 정수.

### 예시

- 입력 인자: `[[3,9,9,2]]`
- 반환값: `1`
- 설명: 최댓값 9는 인덱스 1과 2에 있고 먼저 나온 위치 1을 반환한다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

## 1. 문제를 계산으로 번역하기

값의 최대와 동률일 때 작은 인덱스라는 두 조건을 함께 만족시킨다.

## 2. 첫 풀이를 평가하고 방법 고르기

정렬하면 원래 위치를 별도로 저장해야 한다. 순서대로 읽으며 더 클 때만 교체하면 동률 규칙까지 해결된다.

## 3. 손으로 실행해 보기

[3,9,9,2]: best=0. 9>3이므로 best=1. 다음 9는 같으므로 유지. 2도 유지.

## 4. 구현 순서와 맞는 이유

1. 첫 원소를 최선으로 정한다.
2. 두 번째부터 현재 최선과 비교한다.
3. 엄격히 더 클 때만 best를 바꾼다.

앞에서부터 순회하므로 같은 값일 때 유지하면 최초 위치가 보존된다. 더 큰 값만 교체하므로 최대도 유지된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(durations) {
  let best = 0;
  for (let i = 1; i < durations.length; i++) {
    if (durations[i] > durations[best]) best = i;
  }
  return best;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

`>=`로 갱신하면 마지막 동률 위치를 반환한다. 반환은 시간 값이 아니라 인덱스다.

## 7. 복잡도

n=구간 수. 시간 O(n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

최댓값 문제에서는 ‘무엇을 반환하는가’와 ‘동률 규칙’을 먼저 분리한다.
