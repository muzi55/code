# 07. 안내문 모음 개수

목표: 문자 정규화 후 동일한 기준으로 판정한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

text에 들어 있는 영어 모음 a,e,i,o,u의 개수를 대소문자 구분 없이 반환하라. 공백과 숫자는 세지 않는다.

### 입력·반환·제한

길이 0~100,000. 영문 대소문자, 숫자, 공백만 포함.

### 예시

- 입력 인자: `["Air BUS"]`
- 반환값: `3`
- 설명: Air BUS의 모음은 A,i,U 세 개다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(text)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

각 문자를 소문자로 바꾼 뒤 모음 집합에 포함되면 1을 더한다.

## 2. 첫 풀이를 평가하고 방법 고르기

includes가 반복문 안에 있지만 검사 대상 'aeiou'의 길이는 언제나 5다. 따라서 n²이 아니라 O(n)이다.

## 3. 손으로 실행해 보기

'Air BUS' → A(a) 통과, i 통과, r 제외, 공백 제외, B 제외, U(u) 통과, S 제외.

## 4. 구현 순서와 맞는 이유

1. count를 0으로 둔다.
2. 문자 하나를 소문자로 바꾼다.
3. 고정 문자열에 포함되면 센다.

각 문자마다 정확히 하나의 모음 여부 판정을 한다. 대소문자만 바꾸므로 다른 문자가 모음으로 바뀌지 않는다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(text) {
  let count = 0;
  for (const ch of text) {
    if ('aeiou'.includes(ch.toLowerCase())) count++;
  }
  return count;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

y는 이 문제에서 모음이 아니다. 모음 종류 수가 아니라 등장 횟수라 'AAA'는 3이다.

## 7. 복잡도

n=길이. 시간 O(n), 결과 제외 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

대소문자 무시 문제는 정규화→판정으로 나눈다. 반복문 내부 함수의 입력 크기도 확인해야 복잡도를 정확히 계산한다.
