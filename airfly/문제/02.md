# 02. 짐 무게의 부호 합계

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

weights[i]는 짐 무게다. loaded[i]가 true이면 싣고 false이면 내린다. 초기 무게 0에서 최종 변화량을 반환하라. 변화량은 음수일 수 있다.

### 입력·반환·제한

두 배열 길이는 같고 0~100,000. weights[i]는 0~1,000 정수, loaded[i]는 boolean.

### 예시

- 입력 인자: `[[5,2,4],[true,false,true]]`
- 반환값: `7`
- 설명: 5를 더하고 2를 빼고 4를 더하면 7이다.

## 1. 문제를 계산으로 번역하기

true 기록은 +weight, false 기록은 -weight로 바꿔 합한다.

## 2. 첫 풀이를 평가하고 방법 고르기

두 배열을 따로 정렬하면 대응이 깨진다. 인덱스 하나로 두 배열을 함께 읽는 O(n) 순회가 자연스럽다.

## 3. 손으로 실행해 보기

[5,2,4], [true,false,true]: total 0 → 5 → 3 → 7.

## 4. 구현 순서와 맞는 이유

1. total=0을 둔다.
2. i로 두 배열의 같은 위치를 읽는다.
3. loaded[i]에 따라 더하거나 뺀다.

각 기록의 변화량은 다른 기록과 독립적이다. 모든 부호 있는 변화량의 합이 최종 변화량이다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(weights, loaded) {
  let total = 0;
  for (let i = 0; i < weights.length; i++) {
    total += loaded[i] ? weights[i] : -weights[i];
  }
  return total;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

음수 답을 0으로 바꾸지 않는다. 이 문제는 실제 적재 가능 여부가 아니라 변화량 계산이다.

## 7. 복잡도

n=기록 수. 시간 O(n), 추가 공간 O(1). 최대 절댓값 10^8로 JS 안전 정수 범위 안이다.

## 8. 다음 문제에서 꺼낼 판단
