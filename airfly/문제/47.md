권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

오름차순이며 중복 없는 예약 번호 ids에서 target의 인덱스를 반환하라. 없으면 -1.

### 입력·반환·제한

길이 0~100,000, 번호와 target은 0~1,000,000 정수.

### 예시

- 입력 인자: `[[3,8,12,20],12]`
- 반환값: `2`
- 설명: [3,8,12,20]에서 12의 인덱스는 2다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(ids, target)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

중간 값을 확인하고 정렬 성질로 불가능한 절반을 버린다.

## 2. 첫 풀이를 평가하고 방법 고르기

한 번의 선형 탐색도 가능하지만 이미 정렬되어 있어 이분 탐색을 연습한다. 정렬되지 않은 배열을 매번 정렬하면 이득이 사라질 수 있다.

## 3. 손으로 실행해 보기

[3,8,12,20],12: left=0,right=3,mid=1(8)→left=2. mid=2(12)→2 반환.

## 4. 구현 순서와 맞는 이유

1. left=0,right=n-1.
2. left≤right일 때 중간 인덱스를 계산한다.
3. 일치하면 반환, 작으면 left=mid+1, 크면 right=mid-1.
4. 구간이 없어지면 -1.

제외한 절반은 정렬 순서 때문에 목표를 포함할 수 없다. 매번 mid까지 제거해 구간이 반드시 줄어든다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(ids, target) {
  let left = 0;
  let right = ids.length - 1;
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (ids[mid] === target) return mid;
    if (ids[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

left=mid처럼 쓰면 한 칸 구간에서 멈추지 않을 수 있다. 빈 배열은 right=-1이라 바로 -1.

## 7. 복잡도

n≥1에서 시간 O(log n), 빈 배열 O(1). 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단

이분 탐색은 ‘버리는 절반에 답이 없다’를 증명하는 탐색이다. 중복의 첫 위치 찾기는 별도 변형이다.
