## 1. 문제를 계산으로 번역하기

2부터 살아 있는 수의 배수를 지우고 끝에 남은 수를 센다.

## 2. 첫 풀이를 평가하고 방법 고르기

각 수를 개별 검사하는 풀이도 출발점이지만 반복되는 약수 검사가 많다. 에라토스테네스의 체로 범위 전체의 판정을 공유한다.

## 3. 손으로 실행해 보기

n=10: 2의 배수 4,6,8,10 제거. 3의 배수 9 제거. 남은 2,3,5,7.

## 4. 구현 순서와 맞는 이유

1. 모두 true로 만들고 0,1을 제외한다.
2. p*p≤n까지 살아 있는 p를 찾는다.
3. p*p부터 p씩 증가시키며 false로 바꾼다.
4. true 수를 센다.

합성수는 √n 이하 소인수를 가지므로 그 배수를 지울 때 제거된다. p*p보다 작은 p의 배수는 더 작은 소인수 단계에서 이미 지워졌다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  if (n < 2) return 0;
  const prime = Array(n + 1).fill(true);
  prime[0] = prime[1] = false;
  for (let p = 2; p * p <= n; p++) {
    if (!prime[p]) continue;
    for (let multiple = p * p; multiple <= n; multiple += p) prime[multiple] = false;
  }
  let count = 0;
  for (let i = 2; i <= n; i++) if (prime[i]) count++;
  return count;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

p부터 지우면 소수 자신까지 지운다. 배열은 n을 포함해야 하므로 길이 n+1.

## 7. 복잡도

시간 O(n log log n), 공간 O(n). 처음에는 ‘배수를 공유해 지운다’는 동작 이해에 집중해도 된다.
