# 18. 놓친 탑승객 이름

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 중복을 허용하는 명단 차이를 빈도로 처리한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

예약 명단 booked에서 탑승 명단 boarded를 빼면 정확히 한 사람이 남는다. 그 이름을 반환하라. 동명이인이 있을 수 있으며 boarded는 booked에서 한 항목을 뺀 명단이다.

### 입력·반환·제한

booked 길이 1~100,000. boarded 길이는 하나 적다. 이름은 소문자 1~20글자.

### 예시

- 입력 인자: `[["mina","jo","mina"],["mina","jo"]]`
- 반환값: `"mina"`
- 설명: mina가 두 명 예약했지만 한 명만 탔으므로 남은 이름은 mina다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(booked, boarded)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

예약은 +1, 탑승은 -1. 마지막에 1이 남은 이름을 찾는다.

## 2. 첫 풀이를 평가하고 방법 고르기

Set은 동명이인을 한 명으로 합친다. 이름별 정수 카운터가 필요한 문제다.

## 3. 손으로 실행해 보기

booked=[mina,jo,mina] → mina:2,jo:1. boarded=[mina,jo] 처리 후 mina:1,jo:0.

## 4. 구현 순서와 맞는 이유

1. 예약 명단을 집계한다.
2. 탑승자마다 하나씩 뺀다.
3. 값이 양수인 이름을 반환한다.

각 탑승자 한 명이 예약 한 명과 상쇄된다. 문제 조건상 정확히 한 항목만 남으므로 양수인 이름이 답이다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(booked, boarded) {
  const counts = new Map();
  for (const name of booked) counts.set(name, (counts.get(name) ?? 0) + 1);
  for (const name of boarded) counts.set(name, counts.get(name) - 1);
  for (const [name, count] of counts) {
    if (count > 0) return name;
  }
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

일치하는 이름을 Set에서 삭제하면 아직 남은 동명이인까지 없어질 수 있다. 유효한 명단이라는 입력 조건을 사용한다.

## 7. 복잡도

평균 시간 O(n), 공간 O(k). 이름 길이는 최대 20으로 제한된다.

## 8. 다음 문제에서 꺼낼 판단

명단의 더하기·빼기는 빈도 차이로 모델링한다. ‘동명이인 가능’은 Set만으로 부족하다는 단서다.
