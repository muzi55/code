## 문제

n이 1과 자기 자신만 약수로 가지는 2 이상의 정수인 소수이면 true, 아니면 false를 반환하라.

### 입력·반환·제한

0≤n≤1,000,000,000.

### 예시

- 입력 인자: `[29]`
- 반환값: `true`
- 설명: 29는 2,3,4,5 중 어느 것으로도 나누어떨어지지 않으므로 소수다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.

5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(n)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

2 미만을 제외하고 2~√n 사이 나누어떨어지는 값이 하나라도 있으면 false.

## 2. 첫 풀이를 평가하고 방법 고르기

n-1까지 나눌 필요가 없다. 두 인수가 모두 √n보다 크면 곱이 n보다 커지므로 작은 약수가 반드시 존재한다.

## 3. 손으로 실행해 보기

29: d=2,3,4,5 모두 실패→true. 49: d=7에서 나누어떨어짐→false.

## 4. 구현 순서와 맞는 이유

1. n<2면 false.
2. d*d≤n인 d를 검사한다.
3. 약수가 나오면 false.
4. 끝까지 없으면 true.

합성수라면 반드시 검사 범위 안의 약수가 발견된다. 발견되지 않으면 1과 자기 자신 외에 약수가 없다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  if (n < 2) return false;
  for (let d = 2; d * d <= n; d++) {
    if (n % d === 0) return false;
  }
  return true;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

1은 소수가 아니다. 2는 반복문을 한 번도 돌지 않고 true가 되어야 한다.

## 7. 복잡도

시간 O(√n), 추가 공간 O(1).
