## 문제

각 문자에 대해 같은 문자가 이전에 나온 가장 가까운 위치까지의 거리를 배열로 반환하라. 처음 나온 문자이면 -1을 넣는다.

### 입력·반환·제한

길이 0~100,000. 영문 소문자만 포함.

### 예시

- 입력 인자: `["abaca"]`
- 반환값: `[-1,-1,2,-1,2]`
- 설명: abaca에서 a의 두 번째와 세 번째 등장은 각각 직전 a와 거리 2다.

## 1. 문제를 계산으로 번역하기

이전에 봤으면 현재 i에서 last[ch]를 뺀다. 계산 후 last[ch]=i로 바꾼다.

## 2. 첫 풀이를 평가하고 방법 고르기

매번 뒤로 스캔하면 최악 O(n²). 가장 가까운 위치 하나만 저장하면 평균 O(n)이다.

## 3. 손으로 실행해 보기

abaca: a 처음 -1(last a=0), b -1, a는 2-0=2(last a=2), c -1, a는 4-2=2.

## 4. 구현 순서와 맞는 이유

1. Map과 결과 배열을 둔다.
2. 기존 위치로 답을 계산한다.
3. 계산이 끝난 뒤 현재 위치를 저장한다.

갱신 직전 last는 현재 위치보다 앞의 마지막 등장이다. 따라서 거리의 출발점이 항상 가장 가까운 과거다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(text) {
  const last = new Map();
  const result = [];
  for (let i = 0; i < text.length; i++) {
    const ch = text[i];
    result.push(last.has(ch) ? i - last.get(ch) : -1);
    last.set(ch, i);
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

먼저 set하면 자기 자신과 거리가 0이 된다. 인덱스 0도 존재하므로 has를 사용한다.

## 7. 복잡도

평균 시간 O(n), 결과 O(n), Map은 알파벳 26종 이하 O(1).

## 8. 다음 문제에서 꺼낼 판단

‘가장 최근’은 마지막 위치 하나를 유지한다. 최초 위치가 필요하면 처음에만 저장해야 한다.
