# 08. 단어별 첫 글자 바꾸기

## 문제

공백으로 구분된 각 단어의 첫 글자를 대문자, 나머지를 소문자로 바꿔라. 연속 공백과 앞뒤 공백은 그대로 보존한다.

### 입력·반환·제한

길이 0~100,000. 영문 대소문자와 ASCII 공백만 포함.

### 예시

- 입력 인자: `["  hello WORLD "]`
- 반환값: `"  Hello World "`
- 설명: 앞의 두 공백은 유지하고 hello와 WORLD를 Hello와 World로 바꾼다.

## 1. 문제를 계산으로 번역하기

문자마다 ‘공백’, ‘첫 영문자’, ‘나머지 영문자’ 중 하나를 적용한다.

## 2. 첫 풀이를 평가하고 방법 고르기

trim이나 공백을 합치는 정규식은 원문 공백을 잃는다. 원문을 한 번 순회하며 상태를 바꾸면 공백 보존도 자연스럽다.

## 3. 손으로 실행해 보기

'  hello WORLD ': 공백 둘 유지(start=true), h→H 후 false, ello 유지, 공백에서 true, W→W, ORLD→orld.

## 4. 구현 순서와 맞는 이유

1. start=true로 시작한다.
2. 공백은 그대로 넣고 start=true.
3. 영문자는 start에 따라 대/소문자로 넣고 start=false.
4. 배열을 합친다.

start는 매 문자 직전에 ‘앞이 공백 또는 문자열 시작’이라는 뜻을 유지한다. 따라서 단어의 첫 글자만 대문자가 된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(text) {
  const result = [];
  let start = true;
  for (const ch of text) {
    if (ch === ' ') {
      result.push(ch);
      start = true;
    } else {
      result.push(start ? ch.toUpperCase() : ch.toLowerCase());
      start = false;
    }
  }
  return result.join('');
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

split 후 빈 문자열을 filter하면 연속 공백이 사라진다. 공백도 출력 데이터의 일부다.

## 7. 복잡도

n=길이. 시간 O(n), 결과 배열과 문자열 O(n).

    ],
