## 문제

양의 정수는 결제 금액, 0은 아직 취소되지 않은 가장 최근 결제 하나를 취소한다. 취소할 결제가 없으면 0은 무시한다. 남은 결제 합계를 반환하라.

### 입력·반환·제한

기록 0~100,000개, 각 값 0~10,000.

### 예시

- 입력 인자: `[[5,3,0,2]]`
- 반환값: `7`
- 설명: 5 결제,3 결제,0으로 3 취소,2 결제 후 합은 7이다.

## 1. 문제를 계산으로 번역하기

금액은 push, 취소는 pop, 마지막에 남은 금액을 합한다.

## 2. 첫 풀이를 평가하고 방법 고르기

매 취소마다 마지막 결제를 검색할 필요 없다. 배열 끝이 바로 취소 대상이다.

## 3. 손으로 실행해 보기

[5,3,0,2]: []→[5]→[5,3]→[5]→[5,2], 합 7.

## 4. 구현 순서와 맞는 이유

1. 스택을 만든다.
2. 양수는 push, 0은 pop한다.
3. 남은 스택을 합한다.

pop은 가장 마지막에 추가되어 아직 제거되지 않은 결제를 제거한다. 빈 배열의 pop 결과는 사용하지 않으므로 무시 동작이 된다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(records) {
  const stack = [];
  for (const value of records) {
    if (value === 0) stack.pop();
    else stack.push(value);
  }
  return stack.reduce((sum, value) => sum + value, 0);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

총합만 기억하면 취소할 직전 금액을 알 수 없다. reduce에는 빈 스택용 초기값 0을 준다.

## 7. 복잡도

시간 O(n), 공간 O(n).
