# 11. 기준 이상만 남기기

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 필터링과 원래 순서 보존을 구분한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

scores에서 cutoff 이상인 점수만 원래 순서대로 배열에 담아 반환하라.

### 입력·반환·제한

길이 0~100,000. 점수와 cutoff는 0~100 정수.

### 예시

- 입력 인자: `[[70,90,80,90],80]`
- 반환값: `[90,80,90]`
- 설명: 70은 제외하고 90,80,90을 등장 순서대로 남긴다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(scores, cutoff)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

node airfly/test.cjs 11 airfly/practice.cjs

## 1. 문제를 계산으로 번역하기

원소마다 포함 여부를 결정하고 포함할 때 뒤에 붙인다.

## 2. 첫 풀이를 평가하고 방법 고르기

01번은 개수만 반환했지만 여기서는 값과 순서가 필요하다. 카운터 대신 배열을 유지한다. 중복도 그대로 남긴다.

## 3. 손으로 실행해 보기

[70,90,80,90],80: [] → [] → [90] → [90,80] → [90,80,90].

## 4. 구현 순서와 맞는 이유

1. 빈 배열을 만든다.
2. 점수를 순서대로 읽는다.
3. 기준 이상이면 push한다.

읽은 순서대로 뒤에 추가하므로 상대적 순서가 보존된다. 조건에 실패한 값만 빠진다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(scores, cutoff) {
  const result = [];
  for (const score of scores) {
    if (score >= cutoff) result.push(score);
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

Set은 중복을 없애므로 여기서 사용하면 틀린다. 결과가 없어도 [-1]이 아니라 []다.

## 7. 복잡도

시간 O(n), 결과 포함 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단

같은 조건식도 반환 요구에 따라 카운터, 배열, boolean 중 필요한 상태가 달라진다.
