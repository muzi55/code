## 문제

최소 점수가 여러 번 나오면 가장 먼저 나온 한 개만 제거하고 나머지를 원래 순서대로 반환하라.

### 입력·반환·제한

길이 1~100,000. 점수 -100~100.

### 예시

- 입력 인자: `[[3,1,2,1]]`
- 반환값: `[3,2,1]`
- 설명: [3,1,2,1]의 첫 번째 1만 제거해 [3,2,1]을 반환한다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?

## 1. 문제를 계산으로 번역하기

삭제할 인덱스 하나를 찾은 뒤 그 위치를 제외해 복사한다.

## 2. 첫 풀이를 평가하고 방법 고르기

최솟값만 저장하면 중복 중 어느 것을 제거할지 다시 고민해야 한다. 처음부터 위치를 저장하면 정확한 항목을 고를 수 있다.

## 3. 손으로 실행해 보기

minIndex=0(3) → 1(1). 2는 더 크고 마지막 1은 같아 유지. 인덱스 1만 건너뛴다.

## 4. 구현 순서와 맞는 이유

1. 첫 인덱스를 후보로 둔다.
2. 엄격히 작은 값일 때만 갱신한다.
3. 해당 인덱스만 제외한 배열을 만든다.

엄격한 비교가 최초 최소 위치를 보존하고, 인덱스로 제거하므로 한 항목만 빠진다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(scores) {
  let minIndex = 0;
  for (let i = 1; i < scores.length; i++) {
    if (scores[i] < scores[minIndex]) minIndex = i;
  }
  return scores.filter((_, i) => i !== minIndex);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

정렬 후 앞 하나를 지우면 나머지의 원래 순서가 바뀐다. 원소가 하나면 []다.

## 7. 복잡도

시간 O(n), 반환 배열 O(n).

## 8. 다음 문제에서 꺼낼 판단

‘한 개 제거’, ‘모두 제거’, ‘종류 제거’를 먼저 구분하면 자료구조 선택이 쉬워진다.
