## 문제

연속한 정확히 k개 점수의 합 중 최댓값을 반환하라.

### 입력·반환·제한

길이 1~100,000, 점수 -1,000~1,000, 1≤k≤길이.

### 예시

- 입력 인자: `[[2,-1,3,4],2]`
- 반환값: `7`
- 설명: [2,-1,3,4]에서 길이 2의 합은 1,2,7이라 답은 7.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(scores, k)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

새 sum=이전 sum-떠나는 값+새 값.

## 2. 첫 풀이를 평가하고 방법 고르기

매 구간을 다시 더하면 O(nk). 첫 구간만 직접 더하고 나머지는 갱신하면 O(n)이다.

## 3. 손으로 실행해 보기

첫 [2,-1] 합 1. 오른쪽 이동:1-2+3=2. 다시 2-(-1)+4=7.

## 4. 구현 순서와 맞는 이유

1. 첫 k개 합을 만든다.
2. best를 첫 합으로 둔다.
3. i=k부터 scores[i-k]를 빼고 scores[i]를 더한다.
4. best를 갱신한다.

두 연속 창은 k-1개 항목을 공유하므로 바뀌는 두 항목만 반영하면 정확한 합이다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(scores, k) {
  let sum = 0;
  for (let i = 0; i < k; i++) sum += scores[i];
  let best = sum;
  for (let i = k; i < scores.length; i++) {
    sum += scores[i] - scores[i - k];
    best = Math.max(best, sum);
  }
  return best;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

best=0으로 시작하면 전부 음수인 입력에서 실제로 없는 0을 반환한다. 길이는 ‘최대 k’가 아니라 ‘정확히 k’다.

## 7. 복잡도

시간 O(n), 추가 공간 O(1).

## 8. 다음 문제에서 꺼낼 판단
