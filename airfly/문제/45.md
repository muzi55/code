권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

한 번에 1칸 또는 2칸 오를 수 있다. n칸을 정확히 오르는 순서의 수를 반환하라. n=0은 아무 이동도 하지 않는 한 가지 방법으로 센다.

### 입력·반환·제한

0≤n≤40.

### 예시

- 입력 인자: `[4]`
- 반환값: `5`
- 설명: 4칸은 1111,112,121,211,22 다섯 가지다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(n)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

ways[i]=ways[i-1]+ways[i-2]. 마지막 1칸을 붙이는 경우와 2칸을 붙이는 경우를 합한다.

## 2. 첫 풀이를 평가하고 방법 고르기

모든 경로를 직접 나열하면 수가 빠르게 증가한다. 같은 높이까지 가는 경우의 수는 재사용할 수 있다. DP 입문 연결 문제다.

## 3. 손으로 실행해 보기

ways[0]=1, ways[1]=1. ways[2]=2, ways[3]=3, ways[4]=5.

## 4. 구현 순서와 맞는 이유

1. 0칸과 1칸을 각 1로 정한다.
2. 2부터 n까지 이전 두 답을 더한다.
3. ways[n]을 반환한다.

모든 경로의 마지막 이동은 1 또는 2 중 하나이고 두 집합은 겹치지 않는다. 앞부분은 각각 i-1,i-2칸의 모든 경로다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  if (n <= 1) return 1;
  const ways = Array(n + 1).fill(0);
  ways[0] = ways[1] = 1;
  for (let i = 2; i <= n; i++) ways[i] = ways[i - 1] + ways[i - 2];
  return ways[n];
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

공식을 외우기 전에 ways[i]의 뜻을 말한다. ‘순서 무시’인 경우의 수는 이 점화식과 다르다.

## 7. 복잡도

시간 O(n), 공간 O(n). 직전 두 값만 남기면 공간 O(1)로 줄일 수 있다.

## 8. 다음 문제에서 꺼낼 판단

‘마지막 선택별로 분리→더 작은 같은 문제’가 보이면 DP 후보다. 이 문항은 Lv.1 이후 개념 연결용이다.
