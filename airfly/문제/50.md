# 50. 안내 버튼 최소 누름

[학습 지도](../README.md) · [접근법](../개념노트/01-문제를-읽고-풀이를-설계하는-법.md)

목표: 반복 조회를 전처리하고 불가능한 경우를 즉시 판정한다.  
권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

buttons의 각 문자열은 한 버튼을 연속 누를 때 나오는 대문자 순서다. 인덱스 0 문자는 1번, 인덱스 1 문자는 2번 눌러 입력한다. 같은 문자가 여러 버튼·위치에 있으면 최소 횟수를 선택한다. 글자마다 선택이 독립적이며 대기 비용은 없다. 각 target을 입력할 최소 누름 합을 반환하되 없는 문자가 하나라도 있으면 -1을 반환하라. 빈 target은 0이다.

### 입력·반환·제한

버튼 1~100개, 각 길이 1~100. target 0~1,000개, 각각 길이 0~100. 영문 대문자만 사용.

### 예시

- 입력 인자: `[["ABAC","BA"],["ABC","D",""]]`
- 반환값: `[6,-1,0]`
- 설명: ABAC와 BA에서 A,B는 각각 최소 1번, C는 4번이다. ABC는 6, D는 불가능, 빈 문자열은 0.

## 1. 문제를 계산으로 번역하기

문자별 최소 비용 표를 한 번 만든 뒤 target의 각 문자 비용을 더한다.

## 2. 첫 풀이를 평가하고 방법 고르기

매 글자마다 모든 버튼을 뒤지면 조회가 반복된다. 전처리로 단순화한다. 글자 선택 간 영향이 없으므로 각 글자의 최소 비용 합이 전체 최소다.

## 3. 손으로 실행해 보기

ABAC: A=1,B=2,C=4. BA: B를 1로 갱신,A는 1 유지. ABC→1+1+4=6. AD는 D에서 즉시 -1.

## 4. 구현 순서와 맞는 이유

1. 모든 버튼을 읽어 i+1과 기존 최소를 비교한다.
2. target마다 total=0을 새로 만든다.
3. 없는 문자는 해당 target의 -1을 즉시 반환한다.
4. 모두 있으면 합계를 반환한다.

각 글자의 선택이 독립적이라 전체 비용은 개별 비용의 합이다. 각 항을 최소로 고르면 합도 최소다. 없는 글자가 있으면 문장 전체를 완성할 수 없다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(buttons, targets) {
  const cost = new Map();
  for (const button of buttons) {
    for (let i = 0; i < button.length; i++) {
      const ch = button[i];
      cost.set(ch, Math.min(cost.get(ch) ?? Infinity, i + 1));
    }
  }
  return targets.map(target => {
    let total = 0;
    for (const ch of target) {
      if (!cost.has(ch)) return -1;
      total += cost.get(ch);
    }
    return total;
  });
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

앞의 글자를 입력했다고 뒤의 없는 글자를 무시하면 안 된다. total>0은 성공 조건이 아니다. 빈 target의 0도 유효한 답이다.

## 7. 복잡도

B=전체 버튼 문자 수, T=전체 target 문자 수, q=target 수. 평균 시간 O(B+T+q), 비용표 최대 26칸 O(1), 반환 공간 O(q).
