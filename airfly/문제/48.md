권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

0은 빈자리, 1은 사용 중인 R행 C열 seats에서 (row,col)의 상하좌우 중 빈자리 수를 반환하라. 기준 좌석 자체와 대각선은 세지 않는다.

### 입력·반환·제한

R,C는 1~100. row,col은 유효한 0 기준 좌표.

### 예시

- 입력 인자: `[[[1,0,1],[0,1,0],[1,1,1]],1,1]`
- 반환값: `3`
- 설명: 예시 중심 (1,1)의 위·왼쪽·오른쪽은 0이고 아래는 1이라 3이다.

## 코딩 전에 직접 적기

## 1. 문제를 계산으로 번역하기

(r-1,c),(r+1,c),(r,c-1),(r,c+1) 중 범위 안이고 값이 0인 것을 센다.

## 2. 첫 풀이를 평가하고 방법 고르기

전체 좌석을 순회할 필요 없다. 연결 영역을 찾는 문제도 아니므로 BFS는 필요 없다.

## 3. 손으로 실행해 보기

(1,1)에서 (0,1)=0,(2,1)=1,(1,0)=0,(1,2)=0 → 3.

## 4. 구현 순서와 맞는 이유

1. 네 방향 배열을 둔다.
2. 다음 좌표를 계산한다.
3. 행·열 범위를 먼저 확인한다.
4. 빈자리이면 센다.

네 방향을 정확히 한 번씩 검사하고 범위 밖을 제외하므로 상하좌우의 빈자리만 센다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(seats, row, col) {
  let count = 0;
  for (const [dr, dc] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
    const r = row + dr;
    const c = col + dc;
    if (r >= 0 && r < seats.length && c >= 0 && c < seats[0].length && seats[r][c] === 0) count++;
  }
  return count;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

seats[r][c]를 범위 확인 전에 읽으면 없는 행에서 오류가 난다. 중심 좌석은 세지 않는다.

## 7. 복잡도

네 방향만 보므로 시간 O(1), 추가 공간 O(1). 입력 배열 저장 공간은 제외.

## 8. 다음 문제에서 꺼낼 판단

격자는 곧 탐색이라는 뜻이 아니다. 물어본 범위가 이웃 네 칸인지 전체 연결인지 구별한다.
