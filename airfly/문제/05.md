## 문제

n개 간식을 같은 크기의 묶음으로 나누려 한다. 남김없이 나눌 수 있는 묶음 크기를 작은 순서대로 반환하라.

### 입력·반환·제한

n은 1~10,000 정수. 묶음 크기는 1 이상 n 이하.

### 예시

- 입력 인자: `[12]`
- 반환값: `[1,2,3,4,6,12]`
- 설명: 12를 나누어떨어지게 하는 크기는 1,2,3,4,6,12다.

## 1. 문제를 계산으로 번역하기

1부터 n까지 d를 검사하여 n%d===0인 d만 수집한다.

## 2. 첫 풀이를 평가하고 방법 고르기

최대 n이 10,000이므로 전수 검사가 충분하다. 제곱근 풀이도 있지만 여기서는 정답을 빠짐없이 만드는 단순한 기준부터 익힌다.

## 3. 손으로 실행해 보기

n=12. d=1,2,3,4는 통과, 5는 탈락, 6 통과, 7~11 탈락, 12 통과.

## 4. 구현 순서와 맞는 이유

1. 빈 결과 배열을 만든다.
2. d를 1부터 n까지 증가시킨다.
3. 나머지가 0일 때만 넣는다.

모든 가능한 크기를 한 번씩 검사하므로 누락이 없다. 작은 값부터 넣으므로 결과는 이미 오름차순이다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(n) {
  const result = [];
  for (let d = 1; d <= n; d++) {
    if (n % d === 0) result.push(d);
  }
  return result;
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

d=0으로 시작하면 나눗셈 기준이 잘못된다. d<n이면 n 자신이 빠진다.

## 7. 복잡도

시간 O(n), 결과 제외 추가 공간 O(1). 결과 공간은 약수 개수 k에 대해 O(k).

## 8. 다음 문제에서 꺼낼 판단

완전탐색은 나쁜 풀이가 아니다. 먼저 가능한 후보 수를 계산하고 충분히 작으면 그대로 검사한다. 41번에서 큰 범위를 다룬다.
