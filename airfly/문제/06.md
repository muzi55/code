권장 시간: 12~18분 · JS 함수형 문제 · 자체 제작 Lv.1 목표 연습

## 문제

문자열 code의 마지막 4글자만 남기고 앞의 모든 글자를 *로 바꿔 반환하라. 길이가 4 이하이면 그대로 반환한다.

### 입력·반환·제한

길이 0~100,000. 영문 대문자와 숫자로만 구성.

### 예시

- 입력 인자: `["ABCDEFG"]`
- 반환값: `"***DEFG"`
- 설명: ABCDEFG는 앞의 ABC가 가려져 ***DEFG가 된다.

## 코딩 전에 직접 적기

1. 반환해야 하는 것은 값, 개수, 위치, 배열 중 무엇인가?
2. 아래 첫 예시를 종이에 풀면 무엇을 기억해야 하는가?
3. 떠오른 풀이의 최대 반복 횟수를 제한과 비교해 보자.
4. 변수마다 “지금까지 처리한 무엇”인지 한 문장으로 쓰자.
5. 정답 코드 전에 아래 테스트 중 두 개를 손으로 계산하자.

함수 형태: `solution(code)`. 직접 만든 JS 파일에서 구현하고 마지막에 `module.exports = solution;`을 붙이면 테스트할 수 있다.

## 1. 문제를 계산으로 번역하기

0~hidden-1 위치만 가리고 hidden부터 끝은 복사한다.

## 2. 첫 풀이를 평가하고 방법 고르기

각 문자를 조건 분기해도 되지만 구간 두 개로 나눌 수 있다. repeat와 slice로 의도를 그대로 표현한다.

## 3. 손으로 실행해 보기

길이 7 → hidden=3. '*'.repeat(3)는 '***', slice(3)는 'DEFG'. 합치면 '***DEFG'.

## 4. 구현 순서와 맞는 이유

1. 가릴 길이를 계산한다.
2. 그만큼 별표를 만든다.
3. 남길 뒷부분과 이어 붙인다.

두 구간은 겹치지 않고 원래 전체 길이를 덮는다. hidden을 0 이상으로 제한해 짧은 입력도 보존한다.

## 5. JavaScript 정답

<!-- solution -->
```js
function solution(code) {
  const hidden = Math.max(0, code.length - 4);
  return '*'.repeat(hidden) + code.slice(hidden);
}
```

코드를 다시 읽을 때 각 변수와 갱신문을 위의 손풀이에 연결하자. 코드를 닫고 “어떤 정보만 남겼는가”를 설명한 뒤 직접 재작성한다.

## 6. 실수와 반례

길이-4가 음수인 상태로 repeat하면 오류가 난다. 여기서는 ASCII만 다루므로 JS 문자열 인덱스와 한 글자가 일치한다.

## 7. 복잡도

n=문자열 길이. 시간 O(n), 반환 문자열 포함 공간 O(n).

## 8. 다음 문제에서 꺼낼 판단

문자열 편집은 ‘구간 경계’를 먼저 구하면 단순해진다. slice의 끝 인덱스는 포함하지 않는다는 점도 기억한다.
